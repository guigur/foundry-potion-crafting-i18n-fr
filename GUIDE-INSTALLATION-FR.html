Installer la traduction française dans Foundry 14

Cette traduction personnelle couvre les ingrédients, potions, poisons, descriptions, effets, livres de recettes, pages de journal et tables de Potion Crafting & Gathering 0.8.2. Elle utilise Babele. Les fichiers d'origine restent dans leur module et continuent à recevoir ses mises à jour.

Aucune commande à saisir. La méthode recommandée utilise le manifeste GitHub depuis l'interface de Foundry. L'installation manuelle du ZIP reste possible. Le manifeste devient disponible après la publication de la première release.

1. Préparer Foundry

  1. Utilisez Foundry VTT 14 et un monde avec le système dnd5e.
  2. Depuis l'écran de configuration, onglet Add-on Modules / Modules complémentaires, installez ou mettez à jour Babele 2.8.x et Potion Crafting & Gathering. La traduction a été préparée pour la version 0.8.2 de ce dernier.
  3. Gardez votre module habituel de traduction française de Foundry et de dnd5e. Ce paquet ajoute le contenu de Potion Crafting & Gathering.
  4. Si le module propose immédiatement d'importer son contenu, choisissez No / Non pendant la configuration. Vous pourrez importer après avoir vérifié la traduction.

Gatherer et Mastercrafted servent à automatiser la récolte et la fabrication. Leur propre interface appartient à ces modules et ne fait pas partie de cette traduction. Le contenu de référence reste utilisable sans leur automatisation ; certaines fiches de recettes ou de récolte nécessitent leurs types de pages pour s'afficher correctement.

2. Installer depuis GitHub dans l'interface

  1. Depuis l'écran de configuration de Foundry, ouvrez Add-on Modules / Modules complémentaires → Install Module / Installer un module.
  2. Dans Manifest URL / URL du manifeste, collez l'adresse ci-dessous.
  3. Cliquez sur Install / Installer, puis passez à l'étape 3.
https://github.com/guigur/foundry-potion-crafting-i18n-fr/releases/latest/download/module.json

Après publication de nouvelles versions, utilisez Update / Mettre à jour dans la liste des modules. Si le manifeste affiche une erreur 404, vérifiez qu'une release contenant module.json et le ZIP est bien présente dans le dépôt GitHub. Le lien SSH du dépôt et le ZIP « Source code » de GitHub ne sont pas des manifestes Foundry.

Autre possibilité : copier le ZIP manuellement

  1. Décompressez foundry-custom-i18n-fr.zip. Vous obtenez le dossier foundry-custom-i18n.
  2. Dans l'écran de configuration de Foundry, repérez le User Data Path / Chemin des données utilisateur. Il désigne le dossier de données du serveur, qui peut être différent de votre ordinateur si vous jouez sur un hébergement distant.
  3. Arrêtez Foundry. Dans ce dossier de données, ouvrez Data, puis modules.
  4. Copiez foundry-custom-i18n dans Data/modules. Conservez ce nom de dossier exactement.
  5. Vérifiez que le fichier manifeste se trouve directement ici :
Votre dossier de données/
  Data/
    modules/
      foundry-custom-i18n/
        module.json
        scripts/
        languages/
        compendium/
          fr/

Évitez un dossier en double tel que foundry-custom-i18n/foundry-custom-i18n/module.json. Redémarrez ensuite le serveur Foundry. Sur un hébergement distant, effectuez la copie et le redémarrage depuis les outils de votre hébergeur.

3. Activer la traduction dans l'interface

  1. Ouvrez votre monde et connectez-vous comme MJ.
  2. Ouvrez la barre latérale Game Settings / Paramètres du jeu, puis Manage Modules / Gestion des modules.
  3. Cochez Babele, Potion Crafting & Gathering et Potion Crafting & Gathering — Traduction française.
  4. Cliquez sur Save Module Settings / Enregistrer et laissez le monde se recharger.
  5. Dans Configure Settings / Configuration des paramètres, cherchez le réglage général Language / Langue et choisissez Français. Enregistrez, puis rechargez si Foundry le demande.

Avec cette installation, aucun chemin n'est à renseigner dans les paramètres de Babele : le module enregistre automatiquement son dossier français. Les libellés des boutons peuvent varier selon votre traduction de l'interface.

4. Vérifier avant d'importer

  1. Ouvrez l'onglet Compendium Packs / Compendiums de la barre latérale.
  2. Cherchez Fabrication de potions et récolte. Les sept compendiums doivent porter des titres français.
  3. Ouvrez Fabrication de potions — Alchimie, puis Potion d'escalade : sa description doit être en français.
  4. Dans les ingrédients, ouvrez Lichen de givre. En tant que MJ, vous pouvez aussi vérifier les notes secrètes de récolte.
  5. Dans Livres de recettes, ouvrez L'Alchimiste brasseur, puis une recette : vérifiez son texte et les noms de ses ingrédients.
  6. Dans les tables, ouvrez Cueillette : forêts et vérifiez les noms des résultats.

5. Utiliser le contenu dans votre monde

Pour un objet, ouvrez son compendium et faites-le glisser vers l'inventaire du personnage ou vers l'onglet Objets. Pour une entrée de journal, utilisez son action d'importation. Faites ces imports après l'activation de la traduction.

Si vous utilisez l'automatisation de Gatherer ou de Mastercrafted, leurs versions doivent être compatibles avec Foundry 14. La traduction conserve les références et les formules existantes ; elle ne répare pas les éventuels problèmes d'automatisation du module d'origine.

Pour installer les tables de récolte dans le monde, faites un clic droit sur leur compendium, choisissez Import All Content / Importer tout le contenu et conservez les identifiants des documents avec l'option correspondante. Les points de récolte d'origine référencent ces identifiants. Faites de même pour les journaux et les livres de recettes si votre configuration d'automatisation les utilise.

Si Gatherer et Mastercrafted sont installés, vous pouvez aussi utiliser l'importation proposée par le module d'origine : dans ses paramètres, activez Importer le contenu au démarrage, enregistrez et rechargez, puis acceptez la demande. Cette fonction importe les tables, journaux et recettes avec leurs identifiants. Vérifiez d'abord que ces imports ne remplaceront pas des documents que vous avez personnalisés.

Contenu déjà importé en anglais : les objets et journaux du monde sont des copies. L'activation du module ne réécrit pas automatiquement ces anciennes copies. Comparez d'abord avec le compendium traduit et réimportez les documents souhaités. Un import conservant les identifiants peut remplacer une copie existante portant le même identifiant ; un import individuel crée généralement une nouvelle copie. Gardez vos modifications personnelles avant de remplacer quoi que ce soit.

Les outils requis portent désormais les noms Matériel d'alchimiste, Matériel d'herboriste et Matériel d'empoisonneur. Si une recette ne reconnaît pas un ancien outil anglais, importez l'outil traduit du compendium correspondant et vérifiez le réglage de prérequis dans votre module de fabrication.

Autre méthode : uniquement le dossier Babele

Le fichier pcg-translations-local-fr.zip fournit les mêmes traductions de compendiums sans installer le module personnel. Cette méthode ne traduit pas les messages d'importation codés en dur ; pour ceux-ci, utilisez l'installation complète ci-dessus.

  1. Décompressez le ZIP et copiez son dossier pcg-translations dans le dossier Data de votre serveur Foundry. Il doit contenir un sous-dossier fr avec huit fichiers JSON.
  2. Dans le monde, ouvrez Configuration des paramètres → Babele → Translation Files Directory.
  3. Avec le sélecteur de dossier, sélectionnez pcg-translations, pas son sous-dossier fr. Le chemin enregistré doit être pcg-translations, sans le préfixe Data/.
  4. Enregistrez, réglez la langue sur Français et rechargez le monde.

Les JSON sont des fichiers de traduction Babele : ne les chargez pas avec l'action Import Data / Importer des données d'un objet ou d'un compendium. Le sélecteur Babele choisit leur dossier sur le serveur. Vous n'avez pas besoin d'activer simultanément cette méthode et le module personnel. Si Babele utilise déjà un dossier privé pour d'autres traductions, ajoutez simplement les huit fichiers dans son sous-dossier fr existant.

Fichiers anciens et mises à jour

Le dossier legacy-recipes/fr contient également les douze livres JSON de l'ancien format fourni avec le module. Ils sont traduits, mais ne sont pas nécessaires pour les compendiums de la version 0.8.2. Ne les importez que si votre version de Mastercrafted accepte explicitement ce format de livre ; utilisez normalement les livres du compendium actuel.

Les noms propres, adresses web, crédits et références bibliographiques restent inchangés. Les distances conservent les unités et les valeurs d'origine : il s'agit d'une traduction, sans conversion des règles. La description Essence de Dracula est tronquée dans la source : sa fin est signalée en français.

Le paquet a été vérifié par des contrôles de couverture, de structure, de références et de nombres, ainsi que par des tests des adaptateurs d'interface. Il reste à vérifier son comportement dans votre monde Foundry 14, notamment avec vos versions de Gatherer et Mastercrafted. Une mise à jour du module d'origine peut ajouter de nouveaux textes ou modifier ses identifiants.

Pour désactiver la traduction des compendiums, décochez le module personnel dans Gestion des modules et rechargez. Avec la méthode du dossier privé, retirez ses fichiers ou rétablissez votre ancien chemin Babele. Les copies françaises déjà importées dans le monde restent françaises.
